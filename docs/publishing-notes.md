# 公开版整理说明

此仓库是当前个人系统的独立发布副本，不会覆盖日常使用的本机版本。

- 保留主页、财务管理、流水、专项账本、手机各版、投资四模块、阅读库、AI 服务与桌面源码。
- 将设备绝对路径改为项目相对路径；手机服务默认仅监听本机，局域网访问需显式配置。
- 清空真实专项收支与阅读来源；图片账单解析去掉特定个人商户/金额例外；不公开含真实 OCR 样本的测试夹具。
- 保留单次启动与进程归属逻辑；不发布已退役的 LaunchAgent、watchdog 或自动重启脚本。
- 行情与汇率仅接入长桥 API；原第三方市场数据请求已移除。账户持仓需显式启用后主动读取。
- 尚未自动把长桥数据写入原手工持仓账本；历史分时图仍待接入。开户活动奖励由使用者手工核验记录。
- 不携带真实数据、交易记录、私钥、账户令牌、索引、审计、历史备份、运行日志或编译应用。

`docs/export-manifest.json` 记录整理范围，实际启动步骤见部署文档与长桥接入文档。
