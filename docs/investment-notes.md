# 投资感悟与复盘草稿

> 本文是为项目展示准备的可编辑写作草稿，依据项目的模块分类整理。它没有填入作者未经确认的个人经历、真实交易、收益、亏损或投资结论。作者可以结合自己的记录逐段修改，再作为个人感悟发表。

## 为什么把投资拆成四个板块

我希望把正股、期权、港股开户拉新优惠和港股打新分别记录。每一类的操作目的、成本、兑现时间和复盘问题都不同。把它们分开之后，我才更容易说明：这一次结果来自什么，我为它投入了多少时间和资金，以及下一次是否值得重复。

账本记录发生了什么，复盘解释为什么这样做。项目同时保留金额、状态、过程与心得，是为了让数字能够回到具体行动。

**可以补充：** 为什么开始做这个工具；最初想解决的记录困难；四个板块在自己日常使用中的位置。

## 正股：先把持仓表达清楚

我希望查看持仓时，不只看到盈亏，还能看到成本、币种、板块与仓位。页面里的资产趋势和每周操作记录，帮助我把某一天的结果放回更长的记录里。

复盘时，我想问自己：买入理由是否写清楚？持仓变化来自新的判断，还是临时情绪？如果仓位发生变化，我能不能用当时已有的记录解释它？

**可以补充：** 自己如何形成买入理由、如何记录仓位调整、对某次真实操作的重新理解。涉及价格与公司事实时，补充当时的长桥数据、日期和币种。

## 期权：让每一天都有可回看的过程

我希望日内期权记录能够说清交易过程，而不止留下一个当天的盈亏数字。方向、交易截图、买卖点、走势观察、情绪和每日结论放在一起，才有机会回看“当时我在想什么”。

复盘时，我想检查：进场条件是否清楚？有没有临时改变计划？截图中的操作与文字记录是否一致？当天的结论能不能转化成下一次具体可执行的提醒？

**可以补充：** 自己使用交易日历的方式；截图标注如何帮助复盘；一条经过多次记录后仍有用的纪律。不要在没有记录依据时写成普遍有效的交易规则。

## 港股开户拉新优惠：把预计奖励和已经到账分开

我希望记录开户优惠时，把奖励类型、领取状态与实际投入分开。看到一项奖励并不表示已经完成条件，也不表示它已经变成可以使用的现金。

复盘时，我想核对：资格与活动期限是否确认？奖励是否到账？为了完成条件产生了什么费用与时间投入？把这些成本写清后，才能评价这项活动对自己是否有意义。

**可以补充：** 自己如何核对活动条件；如何记录待领取项目；哪些成本容易被忽略。具体活动的金额、资格和截止日期应标注来源与核验时间，不能把旧记录当作当前可用优惠。

## 港股打新：把申购、结果与费用留在同一条记录

我希望每次打新都有一条完整记录：申购、中签或未中签、实际费用、卖出情况与净盈亏。只看中签后的结果，容易漏掉其他申购记录和费用；按券商与日期保存之后，才能回看整个过程。

阅读资料与决定申购也是两个步骤。文章已经有链接，不代表正文已经读到；资料已经导入，不代表方法已经核验。阅读库把这些状态显示出来，帮助我保留判断的依据与缺口。

**可以补充：** 自己希望保留哪些申购理由；怎样核对实际扣费；怎样将读过并核验的资料用于某次决策。尚未读取的文章不要被写成已经掌握的投资方法。

## 我希望这个项目带来的变化

我希望它让我更容易持续记录，减少重复整理，也更容易承认资料不足或判断需要修正的时候。工具可以整理事实，最后的选择与对选择的解释，仍然需要我自己完成。

外部投资数据统一通过长桥 API 获取。手动录入、个人复盘和市场返回值保留各自的来源；缺少数据时保留缺项，不把猜测写成事实。

**可以补充：** 使用工具后已经确认的变化、还想改进的页面、下一阶段希望形成的记录习惯。发布个人版本前，检查每个第一人称表述是否真的符合自己的想法。
