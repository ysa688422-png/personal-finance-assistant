# 服务器搭建与退出

公开版以本机运行和可信局域网记账为目标。GitHub 展示代码与文档；这里的个人服务不需要发布到公网，也没有在仓库中配置 GitHub Pages。

## 运行前准备

- 建议 Python 3.10 或更新版本。手机接收器和 AI 代码主要使用标准库。
- `openssl`，用于手机接收器首次生成自己的本地 HTTPS 证书。
- 现代浏览器。语音识别需要浏览器支持并授权麦克风。
- 可选：Ollama 与对应模型，用于本地财务问答。
- 可选：长桥凭据与网关依赖，用于独立投资数据查询。

下载或克隆仓库后，在仓库根目录执行下文命令。公开包没有真实账本、SQLite 历史、已有证书、配对令牌或 API 密钥；首次启动按代码需要创建运行目录。

## 1. 本机打开财务页面

```bash
SAYI_BIND_HOST=127.0.0.1 python3 手机记账/sync-server.py
```

服务默认提供两个端口：

| 地址 | 作用 |
| --- | --- |
| `http://localhost:4176/home.html` | 电脑上的总入口 |
| `http://localhost:4176/voice-ledger-stable/index.html` | 电脑查看合并版手机记账 |
| `http://localhost:4176/财务管理/index.html` | 财务管理 |
| `http://localhost:4176/支出与收入流水/index.html` | 流水分析 |
| `https://localhost:4175/` | HTTPS 手机入口，首次可能提示自签名证书 |

公开版默认仅监听本机。终端输出是启动是否成功的依据；如果端口被占用，先确认哪个程序占用，不要反复启动或直接终止不相关服务。

在启动服务的终端按 `Ctrl+C`，接收器会结束 HTTPS 服务及同进程的 HTTP 服务。此时手机不能继续向电脑同步，手机已经保存在浏览器中的账本仍在。

## 2. 让手机通过局域网记账

先退出上一步由自己启动的本机接收器，再明确开启局域网模式：

```bash
SAYI_BIND_HOST=0.0.0.0 python3 手机记账/sync-server.py
```

手机与电脑连接同一个可信网络。按服务输出完成以下步骤：

1. 用手机打开输出中的证书下载地址，安装本次机器生成的本地根证书。
2. iPhone 在“设置 → 通用 → 关于本机 → 证书信任设置”中信任刚安装的本地证书。
3. 打开输出的 `https://电脑局域网地址:4175/pair?token=...` 配对链接。
4. 配对成功后进入合并版记账页面，保存一条自己可核对的记录并同步。
5. 在电脑查看接收器状态与流水，核对日期、金额和同步时间。

证书、私钥与令牌在自己的机器生成，不能沿用或提交他人的证书材料。配对链接相当于该本地记账服务的访问凭据，服务日志也应留在本机。

局域网地址变化后，服务会重新检查证书所需地址。手机访问失败时先检查地址、证书信任、配对状态与电脑防火墙。页面的离线缓存只能帮助打开已缓存内容，不能替代网络同步。

## 3. 启动本地 AI 财务助理

AI 使用 Ollama 的对话模型与嵌入模型。当前项目的模型定义见 `个人财务助理/Modelfile`，默认对话模型名为 `sayi-finance:9b`，嵌入模型为 `qwen3-embedding:0.6b`。

先安装并打开 Ollama，确保本机 `http://127.0.0.1:11434` 可用，再按需要准备模型：

```bash
ollama pull qwen3.5:9b
ollama create sayi-finance:9b -f 个人财务助理/Modelfile
ollama pull qwen3-embedding:0.6b
```

下载大小与运行速度取决于模型和硬件。模型服务可复用已经运行的实例，不必为了每个页面重复启动。

```bash
python3 个人财务助理/server.py --no-open
```

打开 `http://127.0.0.1:4188/`。`--no-open` 让启动命令保留在前台、不自动打开浏览器。结束时在这个终端按 `Ctrl+C`。

尚未准备嵌入模型时，可用 `--no-embeddings` 启动：

```bash
python3 个人财务助理/server.py --no-open --no-embeddings
```

此时规则语义检索受限；账本索引和确定性统计仍按已有文件处理，财务问答仍需要对话模型可用。没有账本文件时，空索引不表示已经导入个人数据。

助理默认读取本仓库的白名单路径。可通过以下变量指定另一份自己的账本根目录或运行位置：

| 变量 | 含义 |
| --- | --- |
| `SAYI_FINANCE_ROOT` | 助理自身运行目录，保存索引、审计和修改备份 |
| `SAYI_FINANCE_SOURCE_ROOT` | 财务资料根目录，内部按原有中文目录组织 |
| `SAYI_FINANCE_PORT` | AI 服务端口，默认 4188 |
| `OLLAMA_HOST` | Ollama 地址，默认本机 11434 |

配置路径时应保留助理静态文件和规则文件的正确位置；不要把运行目录改到缺少这些文件的空目录。白名单不是对整个资料根目录进行全盘扫描，投资与工作资料也不会因为配置根目录就自动纳入。

## 4. 启动长桥只读入口

长桥网关依赖固定版本的官方 `longport==4.3.7` SDK。可以在仓库根目录建立独立环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-longbridge.txt
```

长桥凭据通过本机环境变量 `LONGPORT_APP_KEY`、`LONGPORT_APP_SECRET`、`LONGPORT_ACCESS_TOKEN` 提供，不写入前端。完整认证说明与支持接口见 [长桥 API 接入](longbridge.md)。完成配置后，在这个环境中执行：

```bash
python3 tools/longbridge_gateway.py
```

默认端口为 `4190`，仅监听本机，默认按两小时会话运行。可以使用 `--max-seconds` 明确设置本次时长，范围为 1–28800 秒；在途 SDK 请求可能略延迟时限检查。打开完整面板地址 `http://127.0.0.1:4190/洒一投资工具箱/长桥数据.html`；`http://127.0.0.1:4190/长桥数据.html` 是这个端口上的短路径。

若手机接收器也在运行，可以从电脑打开 `http://localhost:4176/洒一投资工具箱/长桥数据.html`。接收器的 `/api/longbridge/*` 只为本机页面同源转发到 `4190`，不会自动启动网关，也不会将投资读取接口开放给局域网手机。短路径 `/长桥数据.html` 不在 `4176` 提供。

已实现股票报价、期权报价、汇率和港股 IPO 日历。原股票持仓、开户奖励和港股打新页面可读取长桥汇率；失败时显示缓存或手动输入状态。持仓、当前价和交易仍由原页面保存，不会被网关自动改写。读取本人的账户持仓需明确开启：

```bash
python3 tools/longbridge_gateway.py --allow-positions
```

网关未配置、无权限或接口不支持时保留错误与缺项，不使用第三方数据补齐。IPO 日历不提供申购与中签结果，开户优惠也需要手动录入核实。

结束时在该网关终端按 `Ctrl+C`；只关闭浏览器页不会停止服务。不要把长桥凭据写进 HTML、前端 JavaScript、截图或 Git 提交。当前只用模拟响应和真实 SDK 方法签名检查验证实现；没有查询真实账户，带认证的在线 API 响应仍待配置后核验。

## 5. macOS 启动入口

仓库保留 `.command` 启动入口和桌面应用源码，以便在 macOS 按需使用。公开包的路径按仓库位置解析，预编译的个人 `.app` 不作为可移植发行包。构建脚本分别为：

- [主页桌面应用](../桌面应用/构建主页桌面应用.command)：生成主页启动器；优先使用已安装的 Chrome 应用窗口，否则打开系统浏览器。
- [AI 财务助理桌面应用](../个人财务助理/桌面应用/构建桌面应用.command)：从 Swift 源码构建独立窗口；需要 macOS 13 或更新版本与系统开发工具。

主页启动器调用仓库根目录的 `启动洒一财务与投资服务.command`，通过服务控制终端启动一次接收器。AI 桌面入口按需使用，首页的“打开财务助理”需要先构建对应 AI 应用；也可以按上文使用命令行访问。

主页 Chrome 窗口与接收器控制终端各自存在。关闭 Chrome 主页窗口本身不会停止接收器；关闭拥有该接收器的控制终端，或在该终端按 `Ctrl+C`，才会停止它启动的服务。复用已有服务时，新窗口不会取得停止该进程的所有权。

AI Swift 窗口关闭时，只停止自己启动的 `4188` 服务，复用的服务继续运行。直接命令行启动的接收器与 AI 则在各自终端按 `Ctrl+C` 退出。启动失败明确提示，不创建登录项、反复弹终端的重试循环或常驻自动重启任务。

## 数据备份与迁移

首页可导出全站数据，各模块也保留自己的导入导出。换浏览器、换电脑或从 HTTP 切到 HTTPS 前先备份，因为浏览器存储按来源隔离。导入后核对记录数量、日期范围和关键字段；有浏览器备份不表示磁盘 JSON 已更新。

运行生成的 JSON、数据库、聊天历史、审计、证书和配对令牌不应提交到公开仓库。公开源码中的示例用于说明字段和界面，不能当作真实账户或行情。

源码与页面素材的使用范围见 [NOTICE.md](../NOTICE.md)。仓库没有授予统一开源许可，第三方组件保留各自许可。

## 关于公网部署

当前 Python 服务面向个人本机与可信局域网场景，仓库没有配置公网访问、云端账户体系或正式托管方案。若要新增云端版本，应先设计认证、用户隔离、HTTPS、备份及服务生命周期，再形成独立部署方案。上传 GitHub 源码本身不等于发布了可访问的私人财务服务。
