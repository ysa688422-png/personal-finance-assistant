# 洒一的个人财务助理

本机专用、只读优先的个人财务分析入口。底层使用 Ollama 的 `sayi-finance:9b`，检索使用 `qwen3-embedding:0.6b`。

## 使用

双击 `启动个人财务助理.command`。页面只绑定 `127.0.0.1:4188`，不会向局域网或互联网开放。
启动器会先检查 Ollama；如果 Ollama 没有运行，会自动打开并等待本机服务就绪。

若 `qwen3-embedding:0.6b` 因网络缓慢没有下载完成，可双击 `继续下载检索模型.command` 断点续传。未安装嵌入模型时，结构化收支计算和 Qwen3.5 9B 回答仍可正常使用，只是暂时没有规则语义检索。

## 对话历史

每次成功问答都会保存到本机 `index/finance.sqlite3`，包括回答对应的来源、数据期间和提示。关闭窗口或重新启动服务不会清空历史；模型仅会读取当前对话最近的有限消息，避免上下文无限增长。

页面可以新建、切换、重命名和删除对话。删除只影响对话记录，不会改动财务原始文件。命中路桥工作或关闭状态投资接口的请求，在写入历史前会被替换成隔离标记，原始敏感文本不会进入对话数据库。

## 数据白名单

- `财务管理/手机记账同步/手机记账-全部同步.json`
- `财务管理/手机记账同步/手机记账-YYYY-MM-导入财务管理.json`
- `数据备份/财务管理/` 中最新的 `资产管理-YYYY-MM-DD.json`
- `个人财务助理/rules/personal-finance-rules.md`

投资目录、全站备份、路桥工作目录不在扫描路径中；即使白名单记录中含工作或投资关键词，也会在入库时排除。

## 写回保护

修改分为“生成建议”和“确认写回”两个请求。确认时会校验文件哈希、备份所有受影响文件、原子写回、重建索引并复核。审计记录位于 `audit/audit.jsonl`。
